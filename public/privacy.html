DATA INTEGRITY // ZERO LOG

KEBIJAKAN PRIVASI & PERLINDUNGAN DATA

Prinsip privasi tanpa kompromi: transparansi pemrosesan tanpa retensi basis data eksternal.

[POIN 01] ARSITEKTUR ZERO-DATA RETENTION

Prinsip Tanpa Penyimpanan Data Akun

Server AM // PROTOCOL dirancang dengan filosofi stateless: kami tidak pernah menyimpan alamat email, kata sandi, token otorisasi, riwayat login, maupun data profil pengguna ke dalam database permanen apa pun. Setiap permintaan HTTP diproses secara sementara di dalam Random Access Memory (RAM) server dan langsung dibersihkan begitu siklus respon selesai.

[POIN 02] KETIADAAN PENGUMPULAN KATA SANDI

Keamanan Magic Link (Tanpa Password)

Sistem sama sekali tidak menyediakan atau meminta input kata sandi. Pengesahan identitas akun mengandalkan secara murni tautan sekali pakai (Out-Of-Band Code / oobCode) yang diterbitkan secara resmi oleh infrastruktur Google Identity Toolkit. Dengan demikian, risiko kebocoran kata sandi adalah nol karena kredensial sensitif tidak pernah melewati gateway kami.

[POIN 03] TRANSMISI ENKRIPSI PIHAK KETIGA

Koneksi Terenkripsi TLS 1.3

Seluruh komunikasi antara klien (browser Anda), server perantara, dan server Google Identity Toolkit / Alight Creative Cloud Functions dilindungi dengan enkripsi Transport Layer Security (TLS) versi 1.3 dengan cipher suite modern berbasis AES-GCM. Tidak ada perantara pihak ketiga lain yang menyadap atau membaca paket data tersebut.

[POIN 04] LOG TEKNIS & TELEMETRI AGREGAT

Hanya Jumlah Numerik Tanpa Identitas

Satu-satunya data yang dicatat pada server adalah counter numerik sederhana (total aktivasi sukses dan jumlah hari ini) yang disimpan secara agregat murni pada file internal server tanpa kaitan apa pun dengan alamat email atau alamat IP pengguna. Kami tidak mengumpulkan log aktivitas per-pengguna.

[POIN 05] PENYELIDIKAN DAN HAK PENGGUNA

Kontak Pengembang

Apabila Anda memiliki pertanyaan teknis atau kekhawatiran terkait arsitektur privasi sistem ini, Anda dapat menghubungi tim pengembang melalui situs resmi di DIAWW.DEV (https://diaww.my.id).
