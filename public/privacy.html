PRIVACY NOTICE // KEBIJAKAN PRIVASI

Arsitektur stateless, zero-data retention, dan nihil penyimpanan kredensial sensitif.

// PRINSIP 01 : ZERO DATA RETENTION

Tidak Ada Database Kredensial

Server MOTION V menerapkan arsitektur tanpa status (stateless). Kami tidak menyimpan alamat email, token otorisasi, riwayat sesi pengguna, maupun parameter akun ke dalam database eksternal apa pun. Setiap permintaan HTTP diproses secara sementara di memori RAM dan dibersihkan seketika.

// PRINSIP 02 : MEKANISME TANPA KATA SANDI

Otentikasi Magic Link

Sistem sama sekali tidak meminta kata sandi email atau akun pengguna. Hak akses divalidasi langsung melalui kode token sekali pakai (oobCode) yang diterbitkan secara resmi oleh infrastruktur Google Identity Toolkit.

// PRINSIP 03 : ENKRIPSI PROTOKOL TLS 1.3

Transmisi Aman

Seluruh komunikasi antara browser pengguna, server perantara, dan Google Cloud Platform dilindungi dengan enkripsi TLS 1.3. Tidak ada pihak ketiga yang memiliki akses ke paket data transmisi.

// PRINSIP 04 : TELEMETRI AGREGAT ANONIM

Penghitung Numerik Anonim

Satu-satunya data yang dicatat pada server adalah counter numerik sederhana (total aktivasi sukses dan jumlah hari ini) yang disimpan secara agregat murni pada file internal server tanpa kaitan apa pun dengan alamat email atau alamat IP pengguna.
