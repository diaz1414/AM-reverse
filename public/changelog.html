VERSION LOG // CHANGELOG

Catatan rilis berurutan mengenai optimasi protokol, peningkatan mitigasi deteksi, dan pembaruan arsitektur antarmuka.

v2.2.0 // NOPIXEL V DESIGN OVERHAUL CURRENT
16 NOVEMBER 2026

[UI/UX 1000% NOPIXEL ALIGNMENT]

  • Penyelarasan visual 1000% dengan NoPixel Studios (nopixel.net) menggunakan tipografi Barlow Condensed, palet Ink/Paper, dan aksen mint brand.
  • Implementasi NoPixel Launch Hero dengan play trigger central, stacked paper badge, dan status telemetry slide.
  • Pembaruan NoPixel signature light paper footer dengan sitemap dan legal link lengkap.
  • Pengaturan tata letak responsif mobile-first untuk kenyamanan layar kecil hingga desktop.

[CORE & PROTOCOL]

  • Penyempurnaan parsing oobCode dari tautan email berlapis (nested URL decoding).
  • Dedicated path router pada server Express: /terms, /privacy, dan /changelog.
  • Atribusi resmi developer DIAWW.DEV ke diaww.my.id.
v2.1.0 // STEALTH DALVIK SUITE 28 OKTOBER 2026

• Penyisipan identitas paket com.alightcreative.motion dan SHA-1 cert fingerprint.

• Multi-proxy IP rotation header injector (x-forwarded-for, x-real-ip).

• Integrasi token refresh session melalui Google Secure Token API.

v2.0.0 // WEB ENGINE MIGRATION 10 OKTOBER 2026

• Transisi dari utilitas CLI murni ke server Express.js modular terstruktur.

• Penyediaan endpoint API: /api/send-link, /api/verify-link, dan /api/stats.

• Telemetri persisten lokal untuk tracking aktivasi harian dan total.

v1.0.0 // PROOF OF CONCEPT 15 SEPTEMBER 2026

• Analisis lalu lintas jaringan pada aplikasi Android Alight Motion.

• Dokumentasi payload verifyPurchase dan pengujian CLI manual.
